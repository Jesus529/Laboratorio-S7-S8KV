LO QUE APRENDI HOY
1. ListView

Aprendimos a utilizar ListView para mostrar varios elementos en una lista y poder desplazarnos por la pantalla. Lo usamos para mostrar los productos y las opciones del menú.

2. ListTile

Aprendimos a utilizar ListTile para ordenar la información en filas, colocando iconos, títulos y descripciones. Lo usamos en el menú principal y en la lista de productos.

3. Listas y mapas

Utilizamos una lista para guardar los productos que registramos. También aprendimos que podemos agregar y eliminar elementos de una lista. En este proyecto usamos una lista de productos, pero todavía no implementamos mapas (Map).

4. Rutas

Trabajamos con la navegación entre las diferentes pantallas, como el menú, el registro, la lista de productos y el perfil. Para este proyecto utilizamos una variable para controlar qué pantalla se muestra, en lugar de usar directamente las rutas de Navigator.

5. Tema global

Aprendimos a configurar un tema general con ThemeData, donde definimos los colores, el fondo y el estilo de los campos de texto para que toda la aplicación tenga un diseño parecido.

6. Cards

Aprendimos a organizar la información usando contenedores, colores, iconos y bordes redondeados. En nuestro código usamos Container para diseñar las secciones, pero todavía no usamos directamente el widget Card.

Funcionalidades de la aplicación

Iniciar sesión con una cuenta de demostración.

Registrar productos con nombre, descripción y precio.

Mostrar los productos registrados.

Eliminar productos con una confirmación.

Editar los datos del perfil.

Mostrar la cantidad de productos registrados.

Validar los campos para evitar guardar información incompleta.

Mostrar mensajes cuando se realiza una acción.
